# Repository workflow

- Develop exclusively in the existing `cloud-portfolio` directory.
- Switch branches in this directory. Do not create additional worktrees, clone directories, or backup repositories.
- Preserve the existing visual style, low-poly models, animations, assets, camera behavior, and zone architecture.
- Keep changes and commits focused. Do not open or merge pull requests without explicit authorization.
- Keep descriptions concise. Do not add co-author trailers or generated authorship metadata.
